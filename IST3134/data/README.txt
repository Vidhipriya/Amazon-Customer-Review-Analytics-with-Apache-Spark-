Dataset download instructions

The raw dataset is not included in this repository because of its large file size.

Download the Amazon US Customer Reviews Dataset from:
https://www.kaggle.com/datasets/cynthiarempel/amazon-us-customer-reviews-dataset

Download or locate this selected file:
amazon_reviews_multilingual_US_v1_00.tsv

Place the file in this folder before running the analysis:
data/amazon_reviews_multilingual_US_v1_00.tsv
